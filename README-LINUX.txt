  ENERGYUTILS — LINUX (v2.1.2)
══════════════════════════════════════════════════════════════

◈ Что это
  Полноценный лаунчер EnergyUtils под Linux (x64), собранный из
  той же кодовой базы, что и Windows-версия. Самообновление
  лаунчера на Linux отключено (Windows-only механика), всё
  остальное работает: мод, клиент, HBJVM-подобная Java
  (Temurin JRE 21), звуки, анти-анализ, проверки, настройки.
  Мод и клиент качаются с GitHub CDN (быстро, 6 потоков).

───────────────────────────────────────────────────────────────
◈ Установка / запуск
  1. Скачай архив EnergyUtils-Linux-2.1.2.tar.gz (GitHub:
     hibera1/launcher → release v2.1.2) и распакуй куда удобно:
       cd ~/Downloads
       tar -xzf EnergyUtils-Linux-2.1.2.tar.gz
     → появится папка linux-unpacked/

  2. Зайди в неё и запусти:
       cd linux-unpacked
       chmod +x energyutils chrome-sandbox
       ./energyutils

  3. Первый запуск всё настроит сам: скачает мод, клиент,
     Java (Temurin JRE 21 с GitHub в ~/.energyutils), звуки/модели.
     Игра и данные живут в ~/.energyutils/game

───────────────────────────────────────────────────────────────
◈ Требования
  - Linux x64 с GUI (X11/Wayland)
  - Интернет на первый запуск (GitHub CDN + Mojang)
  - libfuse2 для sandbox (Ubuntu/Debian):
      sudo apt install libfuse2
  - Если вылетает с sandbox: chrome-sandbox требует setuid:
      sudo chown root:root chrome-sandbox
      sudo chmod 4755 chrome-sandbox
    ИЛИ запусти без песочницы (осторожно):
      ./energyutils --no-sandbox

───────────────────────────────────────────────────────────────
◈ Что отличает Linux-версию
  - Папки: вместо C:\EnergyUtils → ~/.energyutils (переносимо)
  - Java: jre21-linux (Temurin, с GitHub) — не HBJVM.exe, а bin/java
  - Самообновление лаунчера отключено (меню «Обновить лаунчер»
    скажет, что актуально) — новую версию ставь вручную
  - Анти-анализ: нативный слой Windows не используется, работает
    лёгкий скан процессов Linux (gdb/lldb/ida/ghidra и т.п.)
  - Диагностика: zip собирается через tar (нет PowerShell) — ок

───────────────────────────────────────────────────────────────
◈ Обновление версии
  Новые версии для Linux выкладываются так же (tar.gz).
  Качаешь, распаковываешь, запускаешь ./energyutils —
  старый лаунчер можно поверх перезаписать, данные сохранятся
  в ~/.energyutils.
